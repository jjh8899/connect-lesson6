# Connect · Lesson 6 English Studio

5주차 샘플의 활동·피드백 원리를 6과 디지털 소통 주제에 맞게 재구성한 로컬 웹 앱입니다. 기존 Connect Quest와 다른 독립 화면·저장 구조를 사용합니다.

## 실행
1. 압축을 풉니다.
2. START.cmd를 실행합니다. Node.js 22 이상이 필요합니다. 이 컴퓨터에서는 Codex 번들 Node도 자동으로 찾습니다.
3. http://127.0.0.1:4173/ 에 접속합니다. 기존 탭은 새로고침하세요.
4. 이름 또는 별명을 입력합니다. 같은 이름은 기존 학습으로 이어집니다.

## 활동
- Warm-up: 상황과 감정 이모지 연결, 4개, 점수 없음.
- Listening: 스크립트 기반 의미·의도 파악 7문항, 각 5점. 추가 대화 12개를 음원으로 제공.
- Reading: comprehension 2, expression 2, matching 1 = 5문항, 각 5점. Matching은 올바른 연결을 고르는 4지선다.
- Collocation: 문맥에 맞는 표현 선택 8문항, 각 5점.
- Self-review: 영역별 점수, 미응답/건너뜀, 오답 재도전, 선택형 자기평가, 같은 기기에서 친구와 번갈아 선택하는 대화 활동.

총 20문항·각 5점·100점, 전 문항 4지선다, B1 목표로 제작. 공인 난이도 검증 시험은 아닙니다. 문법·쓰기·받아쓰기는 없습니다. 정답은 첫 제출에만 점수를 부여합니다. 힌트 감점 없음. 건너뛰기는 최초 0점으로 기록되며 복습할 수 있습니다. 복습 결과가 좋아져도 첫 평가 점수는 유지됩니다.

## 음원
`dist/audio/`에 WAV 16개가 들어 있습니다. 앱에서 별도 업로드 없이 바로 재생합니다.
- 제공 스크립트 대화 12개
- 읽기 도입부 1개
- Dohun, Dami, Seoha 본문과 각 2개 조언: 3개

듣기 12개는 Microsoft Edge 신경망 합성음으로 제작했습니다. 여학생(선택 3번 Aria), 남학생(선택 2번 Brian), 성인·보조 역할(Jenny)을 구분하고 대사 사이에 쉼을 넣었습니다. 실제 중학생 녹음이나 교과서 원음은 아닙니다. 생성할 때만 인터넷을 사용하며, 앱은 저장된 WAV를 재생합니다. 본문 읽기 4개도 밝은 성인 여성 느낌의 Jenny 신경망 합성음으로 제작했습니다. 기본 속도와 약간 밝은 음높이로 본문과 조언을 읽습니다. '(Music turns on.)'은 효과 지시이므로 발화/음악 생성에서 제외하고 대본에만 남겼습니다. 읽기 화면에는 음원 저장, 0.8/1/1.2배속, 처음부터 듣기를 제공합니다.

네트워크 음성 API·음성인식·LLM을 호출하지 않습니다. 학습 안내와 추천은 답안/정답률에 따른 규칙 기반입니다.

## 기록
이름별로 현재 브라우저 localStorage에 저장합니다. 계정 인증이나 다른 기기 동기화는 아닙니다. 공용 기기에서는 다른 학생의 기록을 열람할 수 있습니다. 개인 정보 대신 별명을 권장합니다. 결과 JSON을 내려받을 수 있습니다. 기존 버전의 기록은 삭제하지 않고 별도 키로 보존합니다.

## 검증
- `node --test lesson6.test.mjs`: 문항 수와 배점, 빈 답안/매칭 처리, 중복 채점, 복습, 학생 분리, PCM 음원 16개 검증.
- 브라우저: 이름→워밍업→듣기→읽기→Self-review, 미응답 경고, 정답 점수, 매칭, 건너뜀→재도전 흐름 확인.
- 듣기 파일과 읽기 낭독 파일 재생 및 0.8배속 확인. 1280px/390px 화면 확인.
- 오디오 Range 요청/416 응답, 과거 문법·튜터 모듈 접근 차단 확인.

## 구현 자료
Windows 로컬 음성 파일 생성: https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer.setoutputtowavefile?view=netframework-4.8.1
듣기 재생성: `generate-dialogue-natural.py`와 `audio-jobs.json`을 사용합니다. Python 의존성 edge-tts, imageio-ffmpeg 및 인터넷 연결이 필요합니다. 역할별 설정은 `dialogue-voice-manifest.json`에 기록되어 있습니다. Reading 재생성은 `generate-reading-natural.py`이며 역할 설정은 `reading-voice-manifest.json`에 기록합니다. 기존 로컬 음성 생성기는 `generate-audio.ps1`입니다.

커버에는 메뉴를 표시하지 않으며, 학습 시작 후에는 Warm-up → Listening → Reading → Collocation → Self-review 메뉴를 동일하게 사용합니다. 본문을 먼저 듣고 읽은 뒤 연어 표시 버튼을 눌러 밑줄을 볼 수 있습니다. 이전 14문항 기록은 보존하되 새 평가 점수에는 합산하지 않습니다.

채팅 미션: 정오답에 따라 가상 친구의 표정과 답장이 바뀝니다. 직접 답한 서로 다른 3문항마다 스티커를 모으며, 복습 성공에는 성장 도장이 표시됩니다. 보상은 첫 풀이 점수에 영향을 주지 않습니다.
